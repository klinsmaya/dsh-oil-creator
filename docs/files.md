# 项目文件夹约定

默认项目库是 `~/Documents/定责项目`。每个子文件夹是一家公司。

## 识别

- 名字符合 `YYYY-MM-DD_公司名`
- 或者里面有 `定版/` 或 `AGENTS.md`

## 骨架

```
2026-09-15_星河餐饮/
├── AGENTS.md
├── 定版/
│   ├── 画像.md
│   ├── 战略屋.md
│   ├── 逻辑链.md
│   ├── 衡量.md
│   ├── 路径.md
│   ├── RACI.md
│   ├── 纵向到底.md
│   ├── 环境盘点.md
│   ├── 三明确.md
│   ├── 一书一会.md
│   ├── 责任书.md
│   └── 历史/          # 改版前的旧稿
└── 材料/
```

`定版/` 只能由 `dz_finalize` 写入。材料夹只列出文件名，插件不解析内容。

工作台状态（会话绑定、待补、跳过、改版、复核、签约）在 `~/.dsh-dingze/overlay.json`。未知 version 会拒绝读取。
