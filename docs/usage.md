# 使用说明

定责工作台把项目库放在左侧，对话在中间，选中项目后右侧打开 Inspector。

## 侧栏

- 标题是公司名。
- pill 显示 `第一章 · 画像`、`待签约` 或 `已收官`。
- 下一行是 `待补 n · 卡点 m · 相对时间`。没有待补时只显示时间。
- 点一行打开 Inspector。右上角新建会在对话里起草「新建定责项目：」。

## Inspector

五个 tab：概览 / 定战略责 / 定目标责 / 定行动责 / 材料。

概览按章列出每一步的人话状态（进行中、已定版、跳过 · 待补、改版中、需复核）。当前步有三颗按钮：

- **定版**：提交「我点头，这步定版：…」
- **改版**：只起草「改版…」
- **标待补**：只起草「标待补：…」

章 tab 显示该章已定版的 Markdown。没有文件时写「这一步还没定版」。RACI 用表格渲染。材料 tab 列出 `材料/`，并预览 `AGENTS.md`。

## 设置

设置卡片标题是「定责工作台」：

- 项目库目录
- 额外可跳过的步骤（编号，逗号分隔；前面加 `!` 表示这一步不可跳过）
- 选中项目时打开详情

## 助手约定

开场先看进度。定版先预览，你点头后再写入。还没定版时不要让助手直接改 `定版/`。
