# 定责工作台

DeepSeek Harness 插件，帮经营团队按定战略责、定目标责、定行动责走完定责。

左侧是项目库，中间是对话，右侧 Inspector 看当前步和定版稿。磁盘文件是真源：定版只能经工具写入，先预览，你点头后再落下。

## 安装

把本包装进 DeepSeek Harness 的 web profile。`cordis.patch.yml` 会关掉官方侧栏，换成「项目库」。卸掉插件后官方侧栏会回来。

设置页名称是「定责工作台」。默认项目库在 `~/Documents/定责项目`，工作台状态在 `~/.dsh-dingze/overlay.json`。

## 项目文件夹

每个公司一个子文件夹，默认名字是 `YYYY-MM-DD_公司名`：

```
2026-09-15_星河餐饮/
├── AGENTS.md
├── 定版/          # 只由 dz_finalize 写入；旧稿进 定版/历史/
└── 材料/          # 插件只列出，不解析
```

文件夹名符合 `日期_公司名`，或者里面有 `定版/` / `AGENTS.md`，就会出现在侧栏。

## 三章十一步

| 章 | 步骤 |
|---|---|
| 第一章 定战略责 | 画像 → 战略屋（内容共识）→ 逻辑共识 → 衡量共识 |
| 第二章 定目标责 | 路径支撑 → 横向到边（RACI）→ 纵向到底 |
| 第三章 定行动责 | 环境盘点 → 三明确 → 一书一会 → 责任书签约 |

画像是会话前置，书里没有独立章。路径优先级和关键项目并进「路径支撑」。对人只说人话名，不念步骤编号。

可跳过：逻辑共识、衡量共识、纵向到底、环境盘点、一书一会。设置里可以用步骤编号覆盖。

## 怎么用

1. 侧栏点新建，或让助手建「星河餐饮」这样的项目。
2. 开场看进度。当前步用 Inspector 的「定版 / 改版 / 标待补」。
3. 定版会先预览。你明确点头后，助手才把稿子写入 `定版/`。
4. 卡点待补会挡住下一步定版。跳过、改版、签约也走对应工具。
5. 全部走完并签好责任书后，侧栏 pill 变成「已收官」。

对话里可以用 `@当前项目`，或 `/step` 插入「看要点：画像」这样的句子。

## 工具

`dz_guide` `dz_status` `dz_create_project` `dz_finalize` `dz_pending` `dz_skip` `dz_reopen` `dz_sign`

定版校验顺序：未知步骤 → 顺序不对 → 还有卡点待补 → 缺少正文。

## 开发

```bash
pnpm install --frozen-lockfile
pnpm check
```

需要 Node ≥ 22.19。配套教练人设 `dingze-coach` 不在本仓库。
